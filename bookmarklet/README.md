# SmashMateCard ブックマークレット版

Chrome拡張をインストールできない環境（スマホ等）で、同等の機能を利用できます。

## ブックマークレット

以下のコードをブックマークのURLとして登録してください。

```
javascript:void(fetch('https://cdn.jsdelivr.net/gh/jun-suzuki1028/SmashMateCard@main/bookmarklet/smashmate-card.js').then(function(r){return r.text()}).then(function(t){eval(t)}))
```

## スマホでの登録方法

### Android (Chrome)
1. このページの「ブックマークレット」のコードをコピー
2. 適当なページをブックマークに追加（名前は「SmashMateCard」にする）
3. ブックマークマネージャーを開き、今追加したブックマークを編集
4. URLを上記コードに書き換えて保存

### iPhone (Safari)
1. このページの「ブックマークレット」のコードをコピー
2. 適当なページをブックマークに追加（名前は「SmashMateCard」にする）
3. ブックマークを編集し、URLを上記コードに書き換えて保存

## 使い方

1. smashmate.net にログイン
2. マイページまたはユーザーページを開く
3. 対戦を始める前にブックマークレットをタップ/クリック
4. その日初めて開くと、最新の終了済み対戦IDを基準に保存し、0勝0敗から計測
5. 対戦後は「更新」するか、再びブックマークレットを開いて戦績を表示・保存・共有

基準はユーザー・シーズン・日本時間の日付ごとに保存します。開き直しても同じ日の基準は変わりません。日付が変わった後の最初の取得では、新しい基準を保存します。カードの日付は日本時間です。

対戦後に初めて開いた場合や、集計範囲を変更したい場合は「基準の対戦ID」に入力し、「IDを変更」を押してください。指定した対戦自体は含めず、その次の対戦から集計します。対戦中止は勝敗に数えません。`0` を指定するとシーズン最初から集計するため、前日以前の対戦も含みます。「現在から計測し直す」は最新の終了済み対戦IDで基準を上書きします。

カードが示すのは「計測開始以降の戦績」です。その日の全試合が自動的に含まれるわけではありません。基準IDが見つからない場合や履歴の取得に失敗した場合はカードを表示せず、IDの変更や再取得を案内します。失敗したIDへの変更は保存しません。

## 注意事項

- smashmate.net へのログインが必要です
- 集計時に smashmate.net のプロフィール・ランキング・対戦履歴を読み取ります。対戦結果などサイト上のデータは変更しません
- 基準IDは smashmate.net の localStorage に `smc:v2:` 名前空間で保存します。Chrome拡張版の保存領域とは独立しているため、基準は共有されません
- 集計はブラウザ内で行います。ユーザー名や戦績を集計用の外部サーバーに送信する処理はありません
- スクリプトの読み込みには jsDelivr CDN への通信が発生します
- 「Xに投稿」を押すと、戦績テキストを付けた X の投稿画面が開きます。投稿は自身で確定してください
- ブラウザによってはブックマークレットが動作しない場合があります

## 開発

編集対象はルートの `tracking.js`（取得・集計処理）と `bookmarklet/source.js`（画面・カード描画）です。配布用の `bookmarklet/smashmate-card.js` は生成物です。

```sh
npm run build:bookmarklet
npm run check:bookmarklet
npm test
```

ビルドは2つのソースを単一の関数スコープにまとめます。実行時に別の JavaScript ファイルを取得する必要はありません。変更を配布するときは生成済みファイルもコミットしてください。
